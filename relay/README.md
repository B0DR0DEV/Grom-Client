# Grom relay — «свой Hamachi» для каждого пользователя

Один общий сервер обслуживает всех пользователей лаунчера, но каждому выдаёт **свой изолированный адрес**
вида `x7k2m9pq4a.play.example.com`. Адрес случайный (10 символов), поэтому чужой человек не может его угадать.
Через relay проходят только настоящие рукопожатия Minecraft — как универсальный прокси его использовать нельзя.

## Развёртывание (один раз, ~15 минут)
1. VPS с белым IP (Ubuntu/Debian). Вес нагрузки — это игровой трафик ваших пользователей: выбирайте тариф с запасом по каналу.
2. Домен и две DNS-записи:
   - `A   relay.example.com   →  IP сервера`  (сюда подключается лаунчер)
   - `A   *.play.example.com  →  IP сервера`  (wildcard, адреса миров)
3. На сервере: `sudo PUBLIC_DOMAIN=play.example.com bash install.sh`
4. В панели хостинга (security group) откройте TCP **7000** и **25565**.
5. В лаунчере откройте `src/main/tunnel.ts` и впишите `host: 'relay.example.com'` в `DEFAULT_RELAY`, затем соберите релиз.
   Пользователям ничего вводить не нужно.

Проверка: `systemctl status grom-relay`, логи — `journalctl -u grom-relay -f`.

## Защита от злоупотреблений (включена по умолчанию)
- Один активный туннель на установку лаунчера; максимум 3 туннеля с одного IP (`MAX_ROOMS_PER_IP`).
- Не больше 10 попыток открыть туннель в минуту с IP; не больше 20 игроков в комнате, 6 с одного IP (`MAX_CONN_PER_ROOM`, `MAX_CONN_PER_IP_ROOM`).
- Туннель закрывается сам, если лаунчер пропал; чужие и «мусорные» подключения отбрасываются.
- Лимита скорости на комнату пока нет. Если появятся злоупотребления — добавьте лимит в `relay-server.js` или `tc`/файрвол.
- Для защиты от DDoS ставьте сервер у провайдера с защитой или за Cloudflare Spectrum/аналогом.

## Режим без домена
Если `PUBLIC_DOMAIN` не задан, relay выдаёт каждому случайный порт из `PORT_MIN..PORT_MAX` (25600–25699, до 100 одновременных миров).
Для публичного сервиса используйте режим с доменом.

## Голосовые звонки (TURN)
Звонки в мессенджере идут напрямую между игроками, но у многих провайдеров и в мобильных сетях прямое соединение невозможно — нужен TURN-сервер.
На том же VPS: `sudo TURN_USER=grom TURN_PASS='длинный-пароль' bash install-turn.sh`, затем открой TCP/UDP 3478 и UDP 49160–49200
и впиши строку, которую выведет скрипт, в `TURN_SERVERS` в `src/renderer/callSignal.ts`. Пароль TURN виден внутри лаунчера —
поэтому в конфиге стоят лимиты (`max-bps`, `user-quota`); используй отдельный пароль, нигде больше не применяй.
