# Конфиденциальность Grom Client

Здесь честно перечислено, какие данные лаунчер отправляет в интернет, куда и зачем. Весь код открыт — любое утверждение можно проверить в исходниках.

## Что лаунчер НЕ делает

- Не видит и не хранит пароль от Microsoft. Вход идёт на официальной странице Microsoft в системном браузере (OAuth + PKCE).
- Не читает файлы за пределами папок Minecraft и самого лаунчера (`.minecraft`, `%USERPROFILE%\.gromclient`, папки сборок). Исключение — перенос из другого лаунчера: он читает только ту папку, которую ты сам выбрал, и ничего в ней не меняет.
- Не показывает рекламу и не продаёт данные.
- Не записывает звонки.

## Куда и что уходит

| Функция | Куда | Что отправляется |
|---|---|---|
| Аккаунт Grom (мессенджер, скины) | Supabase (наш сервер) | Ник, аватар, пароль в виде хеша bcrypt |
| Мессенджер | Supabase | Сообщения общего чата и личные сообщения, вложения |
| Звонки | Между игроками (WebRTC) | Голос зашифрован и идёт напрямую между компьютерами. Если напрямую не соединиться, он проходит через TURN-сервер в зашифрованном виде — сервер его не слышит и не записывает |
| Игра с друзьями | Supabase + relay-сервер Grom | Адрес туннеля и код сборки, пока ты открыт для игры |
| Скины | Supabase, а также Ely.by / Mojang / TLauncher для чтения | Твой скин (публичный, по нику) |
| ИИ-помощник | DeepSeek API | Текст твоего вопроса. Для лимита 10 запросов в день сохраняется обезличенный ID устройства (SHA-256, восстановить из него ничего нельзя) |
| Вход Microsoft | Microsoft, Xbox Live, Minecraft Services | Стандартный вход в Minecraft; токен обновления шифруется средствами Windows |
| Моды, шейдеры, ресурспаки | Modrinth API | Поисковые запросы и скачивание файлов |
| Игра, Java | Mojang, Adoptium/Microsoft | Скачивание файлов игры и Java |
| Проверка обновлений | Supabase | Только запрос «какая последняя версия» |

## Удаление данных

Хочешь удалить аккаунт Grom и сообщения — напиши нам (контакты на [сайте](https://gromclient.devs.li)), удалим.

Локальные данные лаунчера лежат в `%USERPROFILE%\.gromclient` — их можно удалить вручную.
